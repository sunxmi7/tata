### Q-B2 · 语言偏好是否上云 — **已拍〔2026-11-02〕**

| 项 | 内容 |
|---|---|
| **UI 表现** | 语言屏：跟随系统、简/繁/英/日/韩、切换中/失败/返回确认等（约 10 张定稿）。 |
| **决策** | **不上云**：不增 `profile.locale` / 不在服务端存语言偏好；客户端本地存（跟随系统或用户选择）。 |
| **与服务端协作** | 需要本地化文案的接口（帮助、活动等）由客户端在请求头传语言：优先标准 **`Accept-Language`**（如 `zh-Hans` / `zh-Hant` / `en` / `ja` / `ko`）；若项目已约定亦可传 **`X-Language`**（同名语义）。**缺省：** 未带头时按 **`zh-Hans`（简体中文）**。 |
| **OpenAPI / 实现** | `openapi.yaml` 公共 Header（`Accept-Language`）；服务端请求上下文解析（缺省 `zh-Hans`），**本轮不改** help/campaign 等业务响应文案。 |
| **挡住** | ~~profile.locale~~ — **已关闭**；CMS 多语言仍依赖 Q-B6 与运营配置。 |
