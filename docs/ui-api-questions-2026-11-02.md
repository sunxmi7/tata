## B · 本包有设计屏，后端仍缺或仅占位

### Q-B1 · 服务端推送注册

| 项 | 内容 |
|---|---|
| **UI 表现** | 通知设置（今日/明日抽牌提醒、消息通知、选时间）；系统未授权/返回后仍未授权等态。 |
| **代码 / OpenAPI** | `GET/PUT /api/app/v1/notification-preferences` 已有本地提醒开关与时间；**无** `POST /api/app/v1/push/register`（openapi 说明刻意未注册）。 |
| **选项** | (1) 不做服务端推，仅本地通知 + 客户端 OS 授权；(2) 补 push/register 存 device token，后续由运营推。 |
| **建议默认** | 首版 (1)，与当前 OpenAPI 注释一致。 |
| **挡住** | 若选 (2) 需 path、token 字段、隐私文案与推送供应商。 |

### Q-B2 · 语言偏好是否上云

| 项 | 内容 |
|---|---|
| **UI 表现** | 语言屏：跟随系统、简/繁/英/日/韩、切换中/失败/返回确认等（约 10 张定稿）。 |
| **代码 / OpenAPI** | `Profile` 含 `timezone`；**无** `locale` / `language`。 |
| **选项** | (1) 纯客户端 `UserDefaults`/系统 locale；(2) `PUT /profile` 增 `locale` 或多端同步。 |
| **建议默认** | (1) 除非要强一致多端。 |
| **挡住** | (2) 的枚举、默认策略、与帮助/活动 CMS 语言联动。 |
