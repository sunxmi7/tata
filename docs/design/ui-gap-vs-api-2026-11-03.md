1. **首版范围：** 月报 / 年运（Q-B3/Q-B4）是否砍；小组件（Q-B14）是否纯客户端。

3. **占位收口：** Q-B6 / Q-B8 拍板后再填 help/campaign/ledger 数据（仍不编造）。  
4. **已拍不动：** 无 push、无 profile.locale、删号搁置、Admin 不对 App UI。
