# PRD：运营后台数据与运营能力（对照漏洞跟踪「新需求」）

来源：`塔塔-漏洞跟踪记录.xlsx` →「漏洞跟踪记录- 后台」中类型为**新需求**、状态为**运营需求**的条目（约 48 条）。  
**数据分工以** [运营所需数据统计分工.md](./运营所需数据统计分工.md) **为准**（友盟 / 自建统计 / 做不了）。  
对照：现网 `server/internal/tata`、`admin/apps/web-antd`、隐私政策。  
日期：2026-11-27（按分工修订）。

**目标：** 运营能在塔塔后台完成用户与付费核对、活动/弹窗配置；增长类行为数据由友盟出数，不在自建库假装有行为埋点。  
**原则：** 账号与钱以自建为准；活、留、点、渠道包以友盟为准；做不了的不编造。

---

## 1. 可行性总览（按分工）

| 模块 | 出数方 | 现网 | 本 PRD 动作 |
|---|---|---|---|
| 日活 / 留存 / 入口点击与跳出 / 渠道包 / 弹窗曝光点击 | **友盟** | 无 | 接 SDK + 改隐私披露；运营看友盟或后台外链 |
| 日新增、注册趋势、画像、注册地区（IP） | **自建** | 有画像饼图；无日新增看板与地区 | 一期做统计与 IP 回填 |
| 全部用户、付费收入与订单 | **自建** | 有列表/订单半成品 | 一期增强 |
| 弹窗 / 活动**配置** | **自建** | banners / campaigns 半成品 | 一期～二期补配置；曝光数看友盟 |
| 通用：筛选、导出、权限、审计、口径 | **自建** | 权限与审计已有 | 一期补齐 |
| 硬广告 ROI、街道级定位、全量点击回放 | **不做** | — | 见分工文档 §3 |

---

## 2. 范围与分期

### 一期（建议 2～3 周）：自建业务统计与配置

对齐分工文档 §2.1。

- 全部用户：搜索、分页、详情聚合、Excel 导出  
- 付费：订单筛选分页导出 + 收入 / 付费率看板（日/周/月/SKU）  
- 用户概览：注册日新增与趋势、现有画像；**注册记 IP → 异步回填省/市**  
- 弹窗（Banner）：编辑、启停、素材（若定稿）；页上注明「曝光点击见友盟」  
- 通用：时间筛选、导出、审计筛选、口径脚注  

### 二期：活动运营实体（配置与奖励账本）

- 活动 CRUD：名称、素材、起止时间、启停  
- 奖励发放与领取记录（对接额度 / 兑换码等，产品先定奖励类型）  

### 三期：友盟增长数据

对齐分工文档 §1。前置：隐私政策披露第三方统计 + App 接友盟。

- 日活、按端激活、渠道、留存、入口点击/跳出、弹窗曝光点击  
- 塔塔后台：**不自建行为事件库当主分析**；可外链友盟控制台，或只做说明页  
- 仅当「必须按 `user_id` / `reading_id` 下钻到人且法务要求数据只在自有库」时，才考虑自建 `analytics`（与友盟二选一做主口径，默认不上）  

**本期不做：** 硬广告 ROI、街道级定位、未接友盟时编造活/留/点、个人全量点击回放、用友盟数当唯一收入。

## 3. 模块需求

### 3.1 全部用户（自建）

| 需求 | 说明 | 验收 |
|---|---|---|
| 列表管理 | 分页；默认按注册时间倒序；注销/合并可筛选或角标 | 超过 200 条可翻页 |
| ID/关键词搜索 | 用户 ID、邮箱、昵称、手机号（有则搜） | 精确 ID + 模糊昵称/邮箱 |
| 个人详情 | 资料 + 会员/额度/赠送/邀请/年运 + 最近占卜 + 最近订单 | 一处聚合，不散落 |
| 功能使用记录 | **仅业务单据**（占卜、追问等），不是点击轨迹 | 可跳占卜记录（`user_id`） |
| 会员及权益 / 活动邀请 / 付费消费 | 复用现有数据源 | 无数据空态 |
| 数据导出 | 当前筛选导出 CSV/Excel | 与过滤一致；写审计 |

### 3.2 付费管理（自建，财务真相）

| 需求 | 说明 | 验收 |
|---|---|---|
| 累计收入 | 验单成功订单；日/周/月；可按 SKU | 与抽查合计一致 |
| 付费人数与付费率 | 去重付费用户 / 约定分母（§5） | 页脚写清口径 |
| 订单管理 | 时间、SKU、平台、分页、导出 | 可按用户/状态/时间查 |

**金额：** 一期建议订单落库金额快照；否则按 SKU 价并标注估算。  
**友盟付费事件**若开启，只作对照，不以友盟为收入真相。

### 3.3 弹窗管理（配置自建；曝光友盟）

| 需求 | 说明 | 验收 |
|---|---|---|
| 新建/编辑/素材 | 文案；可选图 | 管理端可改且 App 可见 |
| 投放时间 | 已有 `start_at`/`end_at` | 窗外不展示 |
| 展示频率 | 一期「每次进入 / 每天一次」 | 客户端遵守 |
| 启停下架 | `enabled` 或等价 | 关闭立即不展示 |
| 曝光点击 | **友盟自定义事件** | 自建页不编数字；可链到友盟 |

### 3.4 活动管理（配置自建；入口曝光友盟）

| 需求 | 说明 | 验收 |
|---|---|---|
| 新建编辑 | 独立活动实体 | 可建非种子活动 |
| 名称与素材、起止时间 | | 窗外不展示或标已结束 |
| 奖励发放与领取 | 二期 | 有流水可查 |
| 活动入口曝光点击 | **友盟** | 同弹窗 |

### 3.5 用户新增与画像（自建部分）

| 需求 | 本 PRD | 出数方 |
|---|---|---|
| 每日新增、注册趋势 | 一期：`created_at` | 自建 |
| 画像（性别/年龄） | 一期：增强现有 `/users/stats` | 自建 |
| 注册地区 | 一期：注册 IP → 异步省/市；未知单独一档 | 自建 |
| 每日活跃 | 不进自建正式看板 | **友盟** |
| iOS/Android 新增激活 | 不进自建正式看板（可与注册日新增对照说明） | **友盟** |
| 注册渠道 | 不进自建猜测 | **友盟渠道包** |

### 3.6 留存与点击率（友盟）

全部由友盟出数。自建后台一期**不放假看板**；三期最多说明页 + 外链。

App 侧配合：按友盟文档埋启动、页面、自定义事件（首页/探索/活动入口、弹窗曝光点击）。事件名与运营约定后写入附录（可后补）。

### 3.7 通用需求（自建）

| 需求 | 说明 |
|---|---|
| 时间筛选 | 业务日默认 Asia/Shanghai，与现网 cycle 一致 |
| Excel 导出 | 用户、订单、审计 |
| 管理员权限 | 已有模块权限；新页挂 `accounts` / `pay` / 或新建 `ops` |
| 操作日志 | 已有；补筛选 |
| 口径与更新时间 | 自建看板脚注；友盟指标以友盟控制台定义为准并在说明页提示 |

## 4. 信息架构（管理端）

```
运营数据
  ├─ 用户概览     （自建：日新增、画像、地区）
  ├─ 付费概览     （自建：收入、付费率）

  └─ 全部用户

  ├─ 弹窗 / 首页提示窗

系统
  ├─ 操作员与权限
  └─ 操作日志
```

## 5. 指标字典

### 5.1 自建（须在页脚展示）

| 指标 | 默认草案 | 待确认 |
|---|---|---|
| 新增用户 | 当日 `app_users.created_at` 且未合并 | 是否排除注销 |
| 注册地区 | IP 解析省/市；失败 = 未知 | 用哪家 IP 库 |
| 付费人数 | 统计期内 ≥1 笔验单成功 | 退款是否剔除 |
| 付费率 | 付费人数 / 同期新增，或 / 期末注册用户 | 选分母 |
| 收入 | 验单成功金额之和 | 订阅续费归属哪一天 |

### 5.2 友盟（不以自建重算为真相）

| 指标 | 说明 |
|---|---|
| DAU、留存、渠道、入口点击率、跳出、弹窗曝光点击 | 定义以友盟产品为准；与「注册日新增」并列展示时必须标注口径差异 |

## 6. 依赖与风险

1. 友盟上线前须修订隐私政策（第三方统计、收集范围）。  
2. 注册 IP / 地区须在隐私政策中说明用途（安全与统计）。  
3. 订单无金额快照时改价会污染历史收入。  
4. 活动奖励勿另造账本，对接现有额度/兑换码/会员。  
5. 禁止自建与友盟两套「正式」活/留/点并让运营对账打架；默认友盟为准。  

---

## 7. 验收总则

- 无数据：空态，不编造。  
- 友盟未接入前：增长类入口不展示假数。  
- 导出与写操作写审计。  
- 权限按模块控制。
